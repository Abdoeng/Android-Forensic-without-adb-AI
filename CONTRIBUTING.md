# Contributing to Android Forensic Analysis

## Code of Conduct

This project is for authorized forensic analysis only.

## How to Contribute

### Reporting Issues

1. Check existing issues first
2. Provide detailed description
3. Include steps to reproduce
4. Add screenshots if applicable
5. Specify environment details

### Submitting Changes

1. Fork the repository
2. Create feature branch
3. Make your changes
4. Add/update tests
5. Submit pull request

### Code Standards

- Use C# naming conventions
- Include XML documentation
- Write unit tests
- Follow MVVM pattern
- Add logging

### Commit Messages

```
type: subject

body

footer
```

Types: feat, fix, docs, style, refactor, test, chore

### Legal

- Authorized use only
- Comply with laws
- Respect privacy
- Maintain ethics

Thank you for contributing! 🙏
